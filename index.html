About me
A bit about my background and how I work

I'm a DevSecOps Engineer with 4+ years of hands-on experience building secure, automated cloud solutions on Microsoft Azure. My work centers on Infrastructure as Code with Terraform, container orchestration with Docker and Kubernetes (AKS), and CI/CD pipelines built on Azure DevOps and GitHub Actions.

I embed security scanners — Tfsec, TFLint, TruffleHog, Super Linter, and Terratest — directly into the development lifecycle rather than treating them as an afterthought, which has meaningfully cut post-deployment security patches on the teams I've worked with. I've also led cloud transformation initiatives that improved deployment efficiency across enterprise environments.

Beyond the pipelines and clusters, I enjoy mentoring engineers on Terraform, Docker, and container security practices, and I'm currently exploring how GenAI tooling can speed up everyday DevOps automation work.
